# 建筑进度管理（离线手机版）

这是一个**单机版**的网页应用：所有数据都保存在手机浏览器里，不需要 Wi-Fi，也不需要电脑运行服务器。

## 文件说明

- `index.html`：应用本体（界面和全部功能都在这一个文件里）。
- `sw.js`：离线缓存，让应用在没有网络时也能打开。
- `manifest.webmanifest` 和 `icons/`：添加到主屏幕所需的配置和图标。

## 如何在手机上使用

应用需要放在 **https** 地址上才能离线使用并添加到主屏幕。你可以把这几个文件放到任意 https 静态网站服务上，例如 GitHub Pages、Cloudflare Pages、Netlify（都可免费使用）。上传后，在手机浏览器打开该地址：

1. 第一次打开时保持联网，应用会自动缓存到手机里。
2. iPhone（Safari）：分享 → "添加到主屏幕"。Android（Chrome）：菜单 → "安装应用"或"添加到主屏幕"。
3. 之后即使没有网络，也可以从主屏幕打开，数据照常读写。

> 注意：上传到网站的只是应用本体，**数据不会上传**，始终只保存在这部手机上。

## 数据与备份

- 数据保存在手机浏览器的本地存储（IndexedDB）中。清除浏览器数据、卸载浏览器或换手机，数据会丢失。
- 请定期在"数据"里点"导出全部数据"，把生成的 `.json` 文件保存到电脑或网盘。
- 换手机时：在新手机上打开应用，进入"数据"，选择备份文件，勾选确认后导入即可。
- 备份文件包含全部项目、任务、变更历史（含已删除的内容）和照片。

## 功能速览

- **开始日期待定**：新增任务时可勾选"开始日期待定"，之后在任务页面"确定开始日期"。待定任务排在同层最后，地图上显示为虚线边框。
- **预计完成时间**：新增时可填写，也可勾选"预计完成待定"。任务页面可随时"修改预计完成"（需选原因，记入历史）。预计完成不能早于开始日期。
- **顺延规则**：调整开始日期时，预计完成时间按相同天数一起顺延（提前则一起提前），并在变更历史里写明。
- **项目排序**：地图顶部"排序"按钮，用 ▲ ▼ 调整项目上下顺序，项目下的任务跟着一起移动。
- **延伸任务**：未完成的任务也可以"新增延伸任务"，显示在它右侧一格。
- **地图总览**：任务卡片在缩小时始终显示（缩到最小时只显示名称）。
- **提醒（灯泡）**：地图右上角的灯泡，列出"未完成、尚未开始，且距离安排开始只剩 2 个工作日以内"的任务，角标为数量。工作日按周一至周五计算，**暂未扣除法定节假日**。

## 旧数据升级

早期版本的备份文件可以直接导入，缺少的新字段（预计完成、待定日期）会自动补齐为空值，不会丢失已有的任务、照片和变更历史。

## 注意事项

- 手机之间的数据不会自动同步，需要靠导出和导入手动同步。
- 不同浏览器（如 Safari 和 Chrome）的数据互相独立。
- 应用没有登录功能，任何能拿到这部手机的人都能看到数据。
